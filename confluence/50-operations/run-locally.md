# Running this locally

Target: **local**

The platform's **Run locally** tab starts this application from the repositories
bound to it and shows the live output, which is the supported path. This page
records what it does, so the same thing can be done by hand.

- Backend: fastapi
  on python
- Frontend: react
- Database: postgres

Agents commit to each repository's integration branch (`dev`), so that is the
branch to check out to see the current state of the work.
